# 鸟类 v1.7.0 操作手册

- 适用版本：v1.7.0（源码包与 `main` 分支）
- 适用系统：Windows 10/11 64 位
- 更新日期：2026-10-18
- 相关文档：[模型训练环境配置](模型训练环境配置_20261018_001.md)、[README](../README.md)

## 1. 软件简介

「鸟类」是面向 iNaturalist 鸟类数据的桌面应用，覆盖数据采集、数据管理、数据集制作、
模型训练、模型库管理和视觉分析。主界面使用 Python + Tkinter，训练与推理需要独立的
PyTorch 环境。

## 2. 启动软件

### 2.1 小白三步（推荐）

1. 安装 Python 3.10 及以上版本，安装时勾选 **Add python.exe to PATH**。
2. 解压源码包到任意目录（建议路径不含特殊符号）。
3. 双击 `启动爬虫界面.bat`，或在解压目录打开命令行执行：

```
python main.py gui
```

> bat 会优先使用 `pythonw` 启动（无黑色控制台窗口）；没有 `pythonw` 时自动改用 `python`。

### 2.2 命令行启动

在源码目录执行：

```
python main.py          # 查看全部命令
python main.py gui      # 桌面控制台
python main.py stats    # 数据库统计
python main.py health   # 数据库健康检查
```

### 2.3 首次启动会自动完成

- 自动创建 `data/db/` 并初始化 `raw_data.db` 与 `bird_observations.db`；
- 自动创建 `data/model_library/`、`data/drop_inbox/` 等目录；
- 若未安装 Pillow，会弹窗提示一键安装（可跳过，但图片预览不可用）。

## 3. 主界面总览

主界面共 9 个页签：

| 页签 | 用途 |
|---|---|
| 下载控制 | 按类群批量下载 iNaturalist 照片与观察记录 |
| 拖入文件爬取 | txt/csv 清单爬取、本地图片指纹入库、常驻监视 |
| 训练数据集 | 勾选类群，生成 train/val/test 数据集 |
| 模型训练 | 物种分类、部位分割、部位检测训练 |
| 模型库 | 查看、激活、删除、导入模型 |
| 视觉分析 | 物种识别、部位检测、问题互动 |
| 数据浏览 | 查询观察记录，双击打开 iNaturalist 页面 |
| 照片浏览 | 按类群浏览缩略图，双击打开原图 |
| 统计与说明 | 数据库统计、健康检查与安全修复 |

底部状态栏显示当前数据库路径与「就绪」状态。

## 4. 下载控制

### 4.1 选择类群

- 列表中为内置 15 个鸟类科，按住 `Ctrl` 可多选；
- **不选任何类群 = 尽量爬取全部 15 科**；
- 也可在「自定义类群 ID」输入逗号分隔的 iNaturalist 类群 ID，自定义输入优先于上方选择。

内置 15 科：雉科 574、鸭科 6912、鹰科 5067、鸱鸮科 19728、啄木鸟科 17599、
鸠鸽科 2715、杜鹃科 1627、雀科 13685、鹟科 12704、鸫科 15977、鹭科 4929、
鸥科 4342、鹬科 3835、秧鸡科 154、戴胜科 20967。

### 4.2 下载参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| 每类群观察上限 | 0 | 0 = 不限，尽量爬取；重复运行只补增量 |
| 图片尺寸 | large | 可选 large / medium / original |
| 质量等级 | research | research / needs_id / casual / any |
| 下载线程 | 6 | 1–16 |

### 4.3 开始与停止

1. 设置参数后点击「开始下载」；
2. 右侧「运行日志」实时显示进度，`new` 表示新增，`existed` 表示指纹重复已跳过；
3. 需要中止时点击「停止下载」；
4. 「打开数据目录」可直接打开照片与数据库所在目录。

### 4.4 下载结果

- 照片：`data/taxon_<ID>_<名称>/photos/`
- 观察记录与照片清单：对应类群目录下的 CSV
- 数据库：`data/db/raw_data.db`（原始留存）与 `bird_observations.db`（规范主库）

## 5. 拖入文件爬取

### 5.1 文本清单

支持 `.txt`、`.csv`、`.list`，每行一个「类群 ID」或「物种名」，例如：

```
20967
Upupa epops
```

点击「选择 txt/csv/图片文件…」可一次选多个文件，再点击「开始处理」。

### 5.2 本地图片入库

- 点击「选择图片文件夹…」，按文件夹名/子文件夹名解析物种；
- 图片按内容 SHA-256 指纹去重，重复图片自动跳过；
- 源文件保留在原位，不会被删除或移动；
- 也可直接选择若干图片文件。

### 5.3 爬取参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| 每类群上限 | 50 | 仅对需要联网爬取的清单生效 |
| 尺寸 | large | large / medium / original |
| 质量 | research | research / needs_id / casual / any |
| 线程 | 6 | 1–16 |
| 统一类群 | 空 | 填写后覆盖文件夹名判定，全部归入指定物种 |

### 5.4 常驻监视

1. 点击「启动监视 data/drop_inbox」；
2. 将 txt/csv 放入投放目录，程序会自动解析并爬取；
3. 再次点击按钮停止监视；
4. 「打开投放目录」可快速定位 `data/drop_inbox`。

也可以把文件直接拖到 `拖入文件自动爬取.bat` 图标上。

## 6. 训练数据集

### 6.1 生成数据集

1. 左侧「库内类群」勾选参与训练的类群（点击勾选列切换，可搜索、全选、全不选、刷新）；
2. 右侧填写参数：

| 参数 | 默认值 | 说明 |
|---|---|---|
| 数据集名称 | 空 | 生成到 `data/train_datasets/<名称>/` |
| 划分比例 | 8:1:1 | train:val:test |
| 种子 | 42 | 保证划分可复现 |
| 每类最少 | 0 | 少于此数的类跳过，0 = 不过滤 |
| 每类最多 | 0 | 超出按观察随机舍弃，0 = 不限 |
| 标签方式 | 中文名 | 中文名 / 学名 / 类群ID |

3. 点击「生成数据集」；
4. 生成过程按观察级划分，避免同一观察的多张照片同时进入训练集与验证集；
5. 默认使用硬链接零拷贝导出，减少磁盘占用。

### 6.2 已生成数据集

- 列表显示名称、类群数、图片数、生成时间；
- 双击某行或点击「用于训练」直接带到「模型训练」页；
- 「打开目录」「删除」「刷新列表」分别用于定位、删除和刷新；
- 注册表位置：`data/train_datasets/registry.json`。

## 7. 模型训练

### 7.1 先准备训练环境

训练页需要选择含 torch 的 Python 解释器。完整安装步骤见
[模型训练环境配置](模型训练环境配置_20261018_001.md)，依赖清单为
`requirements-train.txt`（源码目录为 `src/requirements-train.txt`）。

操作：

1. 在「训练Python」处填写或浏览选择解释器（如 `.venv-train\Scripts\python.exe`）；
2. 点击「检测依赖」，确认 torch / torchvision / PIL 就绪；
3. 若提示缺库，回到命令行安装后重新检测。

### 7.2 选择任务类型

| 任务类型 | 用途 | 数据要求 |
|---|---|---|
| 物种分类 | 训练物种识别模型 | 按类别分文件夹的数据集 |
| 部位分割 | 训练部位分割模型 | 目录内需有关键点/掩码标注（如 `annotations.csv`） |
| 部位检测 | 训练部位检测器 | 目录内需有关键点标注 |

### 7.3 选择数据

- 「数据目录」选择数据集根目录，点击「扫描数据」查看类别与图片数；
- 或从「已生成数据集」下拉框直接选择；
- 勾选「从中断处续训」可从最近一次断点继续（页面会显示断点信息）。

### 7.4 训练模式

| 模式 | 特点 |
|---|---|
| 适应模式（ad） | 按 GPU 显存/内存/磁盘自动推导批量等资源参数，安全优先、效果优先 |
| 低速模式 | 批量 8 + 混合精度，占用低、速度慢但稳定，适合后台轻度训练 |
| 高速模式 | 大批量 + 混合精度，出结果快、资源占用高 |
| 自定义模式 | 自行设置轮数/优化器/耐心值/批大小/学习率/混合精度 |

说明：轮数、优化器、耐心值、学习率在各模式下都可修改；批大小与混合精度仅自定义模式可手动控制，
其余模式按预设或自动推导。

### 7.5 训练参数

| 参数 | 界面初始值 | 说明 |
|---|---|---|
| 轮数 | 15 | 训练总轮数 |
| 优化器 | adamw | adamw / adam / sgd |
| 耐心值 | 6 | 早停等待轮数，0 = 不早停 |
| 批大小 | 32 | 仅自定义模式可改 |
| 学习率 | 1e-3 | 可按架构调整 |
| 混合精度 AMP | 关 | 仅自定义模式可开关，GPU 上更省显存 |
| 线程 | 0 | 0 = 自动；1–16 = 固定加载进程数 |

### 7.6 数据划分与评估

划分方式：

- 使用目录既有划分（默认）
- 均衡标准级 8:1:1
- 训练优先级 9:0.5:0.5
- 验证强化级 7:1.5:1.5
- 自定义比例

最佳模型判据：Top-1 准确率（默认）、Top-5 准确率、宏平均 F1、验证损失（越小越好）。
程序按该指标保存最佳模型并驱动早停。

### 7.7 开始训练

1. 点击「开始训练」；
2. 页面实时显示每轮验证指标与训练进程输出；
3. 「停止训练」可中途终止；
4. 「打开模型库目录」「打开日志文件」用于定位产物与完整日志。

### 7.8 训练产物

- 训练完成的模型自动进入 `data/model_library/`；
- 命名规则：`基名_月日_版本`（基名在训练页填写）；
- 模型记录写入模型库注册表，可在「模型库」页刷新查看。

## 8. 模型库

工具栏：

| 按钮 | 作用 |
|---|---|
| 刷新 | 重新读取模型注册表 |
| 设为激活模型 | 把选中模型设为视觉分析默认物种模型 |
| 删除 | 删除选中模型（请谨慎操作） |
| 打开模型目录 | 打开 `data/model_library/` |
| 导入外部模型 | 把外部训练产物登记进模型库 |

列表列包括：模型名称、类别数、架构、主指标、日期版本、来源、激活标记（★）。
选中模型后右侧显示预览图与详情。

## 9. 视觉分析

### 9.1 前提

- 已配置含 torch 的训练解释器（与「模型训练」页共用）；
- `vision_system/` 目录完整（源码包默认自带）；
- 首次切换到「视觉分析」页时才惰性加载，首次加载模型可能较慢。

### 9.2 选择图片

- 「选择图片」：从本机选择图片；
- 「从图库选图」：从已爬取的 iNaturalist 图库中选择；
- 载入后显示路径与预览。

### 9.3 识别物种

1. 在「物种模型」下拉框选择模型（默认使用激活模型，可自主切换）；
2. 点击「识别物种」；
3. 结果显示 Top-K 物种与置信度。

### 9.4 部位检测

1. 勾选「启用视觉问答」（会加载模型；不勾选时不加载）；
2. 在「部位模型」下拉框选择检测模型；
3. 选择标记样式：红框或圆圈；
4. 点击「部位检测（全部位）」，进度条显示检测进度；
5. 右侧显示标记结果图，点击部位标记可查看名称。

### 9.5 问题互动

1. 在输入框输入中文问题，例如「这种鸟的翅膀长啥样？」；
2. 点击「提问」，下方显示回答文本；
3. 「清空对话」可清除当前问答记录。

### 9.6 输出位置

标记结果图默认输出到 `vision_system/output/`；模型权重缓存默认在用户目录的
`.cache/huggingface` 下。

## 10. 数据浏览与照片浏览

### 10.1 数据浏览

- 输入关键词（物种名、学名等），选择类群后点击「查询」；
- 列表显示观察 ID、物种、学名、观察日期、地点、观察者、照片数；
- 支持上一页/下一页；双击行可打开对应 iNaturalist 页面。

### 10.2 照片浏览

- 选择类群后点击「刷新」；
- 以缩略图网格显示照片；
- 双击图片用系统看图工具打开原图；
- 未安装 Pillow 时仅显示文件名。

## 11. 统计与说明

- 「刷新统计」：查看观察数、照片数、类群分布、批次记录等；
- 「数据库健康检查」：检查残留、孤儿记录、空批次、重复、同名歧义、两库一致性；
- 「执行安全修复」：在检查出问题后可用，修复前会自动备份整库。

## 12. 命令行用法

| 命令 | 作用 |
|---|---|
| `python main.py` | 查看全部命令 |
| `python main.py gui` | 桌面控制台 |
| `python main.py batch` | 批量下载 15 个鸟类科 |
| `python main.py download --taxon-id 20967` | 下载单个类群 |
| `python main.py drop --file <路径>` | 处理清单或图片文件 |
| `python main.py dataset --out <目录>` | 导出训练数据集 |
| `python main.py panel` | 浏览器数据面板（默认 8765 端口） |
| `python main.py stats` | 数据库统计 |
| `python main.py init-db` | 初始化数据库 |

| `python main.py migrate` | 迁移历史 CSV/JSON 数据 |
| `python main.py copyright` | 查看版权与数字水印 |

常用示例：

```
python main.py batch --max-per-taxon 200 --workers 6 --photo-size large
python main.py download --taxon-id 20967 --max-observations 100
python main.py dataset --out data/train_datasets/demo --splits 8:1:1 --seed 42 --label-scheme cn
```

## 14. 常见问题

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 双击 bat 没反应 | Python 未加入 PATH / pythonw 缺失 | 在该目录打开命令行运行 `python main.py gui` 查看报错 |
| 图片不显示缩略图 | 未安装 Pillow | `pip install pillow` 后重启 |
| 训练页提示缺 torch | 解释器选错或未装训练环境 | 按环境配置文档安装，并在训练页选中该解释器 |
| 视觉分析打不开 | 未找到 vision_system 目录 / 无 torch 解释器 | 确认目录完整，或在 `data/model_library/settings.json` 配置 `vision_system_dir` |
| `torch.cuda.is_available()` 为 False | 装了 CPU 版或驱动异常 | 重装对应 CUDA 轮子并更新显卡驱动 |
| 下载数量为 0 | 类群 ID 错误 / 质量等级过严 / 网络受限 | 换 `needs_id` 或 `any` 重试，检查网络 |
| 下载被限速（429） | 请求过于频繁 | 程序会自动等待；可降低线程数后重试 |
| 同一张图片没有重复入库 | SHA-256 去重生效 | 属于正常行为，避免重复数据 |
| 中文路径下异常 | 个别旧版工具编码问题 | 尽量使用英文路径 |
| 数据库被占用 | 另一进程正在写入 | 关闭其他实例后重试；浏览页只读不写 |
