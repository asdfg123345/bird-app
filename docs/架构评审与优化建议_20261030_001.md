# 鸟类 bird-app 架构评审与优化建议

- 评审对象：`D:\鸟类\bird-app`（src / dev / packaging / docs）
- 评审日期：2026-10-30
- 评审方式：全量通读 + 结构化检索（非运行态），行号以当前工作区文件为准
- 结论摘要：业务闭环完整，工程形态是「一组单机脚本 + 一个 Tkinter 外壳」；
  主要风险集中在 **多份源码并存、文件即状态、GUI 与子进程靠文本耦合、若干主线程阻塞与数据库写法**，
  以及 **发布构建白名单漏包**。

---

## 1. 业务逻辑

### 1.1 四条主线

| 主线 | 入口 | 产物 | 状态存放 |
|---|---|---|---|
| 采集 | `main.py batch/download`、GUI 下载页、拖入页 | `data/taxon_*/photos/` | `raw_data.db` + `bird_observations.db` |
| 治理 | `health` / `cleanup` / `migrate` / `panel` | 健康报告、修复、浏览器面板 | 同上 + 备份文件 |
| 训练 | `dataset` 导出 → 训练页 | 硬链接数据集 | `train_datasets/registry.json` |
| 推理 | 视觉分析页 → `qa_server.py` | 标注图 + 中文结论 | `model_library/registry.json` |

### 1.2 数据流

```
iNaturalist API ──► download_inaturalist.py ──► data/taxon_<id>_<名>/photos/
                         │                              │
                         └──► inaturalist_db_manager ───┴──► raw_data.db
                                                              bird_observations.db
                                                                   │
                drop_crawl_interface.py ───────────────────────────┤（文件夹名解析 + SHA-256 去重）
                                                                   ▼
                                        dataset_exporter.py（观察级 8:1:1、硬链接）
                                                                   │
                                        model_trainer / part_model_training
                                                                   │
                                        model_library/registry.json
                                                                   │
                              gui_app.BirdVqaPanel ──► qa_server.py（torch 子进程）
```

### 1.3 三个「隐形契约」

1. **文件即状态**：模型库、数据集、断点（`last_interrupted.json`）、训练锁（`training.lock`）。
   `registry.json` 是「读—改—写整个文件」，有 tmp+replace 原子写，但**无跨进程互斥**。
2. **子进程即 API**：GUI 拼命令行 + 解析 stdout 文本，进度靠正则
   （`bird_crawler_gui.py` 的 `_DROP_PROGRESS_KIND_RE`），文案一改即静默失效。
3. **路径即配置**：路径全部由 `__file__` 推导，视觉系统目录靠三级探测 + `sys.modules` 兜底。

## 3. GUI 架构

单窗口 + 9 页 Notebook，除「视觉分析」外全部在 `__init__` 内同步构建。

| 病灶 | 证据 | 影响 |
|---|---|---|
| 启动/切页阻塞 | 训练页构建即调 `_detect_train_hardware()`（60s 超时子进程）与 `_count_dataset_images()`（全目录 rglob） | 装了 torch 的机器白屏 5–15 秒 |
| 照片页同步 PIL | 每页 24 张 `Image.open` 在主线程，无缓存；路径解析失败会全盘建索引且永不失效 | 卡顿 + 新图显示「文件缺失」+ 同名串图 |
| 连接误用 | `with sqlite3.connect(...) as conn:` 只提交事务**不关闭**；全项目无 WAL / busy_timeout | 句柄堆积、并发 `database is locked` |
| 契约靠文本 | 进度/结束/指标三种格式并存（正则、`rc=`、`[METRIC]` JSON） | 改日志即断开联动 |

`bird_db_panel.py` 在 `with` 块**外**继续使用连接，正好证明这层误解。

### P0-3 SQLite 加固

新增 `src/db.py`：

```python
from contextlib import contextmanager
import sqlite3
from pathlib import Path

@contextmanager
def connect(path, *, readonly=False):
    p = Path(path)
    if readonly:
        # as_uri() 会百分号编码，避免安装到 "C:\Program Files\鸟类" 这类带空格路径失败
        conn = sqlite3.connect(p.as_uri() + "?mode=ro", uri=True, timeout=5)
        conn.execute("PRAGMA query_only=ON")
    else:
        conn = sqlite3.connect(str(p), timeout=5)
        conn.execute("PRAGMA journal_mode=WAL")
        conn.execute("PRAGMA synchronous=NORMAL")
        conn.execute("PRAGMA foreign_keys=ON")
    conn.execute("PRAGMA busy_timeout=5000")
    conn.row_factory = sqlite3.Row
    try:
        yield conn
        if not readonly:
            conn.commit()
    except Exception:
        if not readonly:
            conn.rollback()
        raise
    finally:
        conn.close()
```

- `bird_crawler_gui.py:3142`、`bird_db_panel.py:342`、`db_health_check.py:111`、`vision_system/gui_app.py:160` 统一改用。
- `inaturalist_db_initializer.py` 建库时设置一次 WAL（持久化，无需每次设置）。

**验收**：并发「浏览 + 导入」10 分钟无 `database is locked`；`PRAGMA journal_mode` 返回 `wal`。

### P0-4 批量提交

`inaturalist_db_manager.py` 增加批提交：

```python
def __init__(..., commit_batch: int = 200):
    self._pending = 0
    self._commit_batch = commit_batch

def _touch(self) -> None:
    self._pending += 1
    if self._pending >= self._commit_batch:
        self.flush()

def flush(self) -> None:
    for conn in (self._raw_conn, self._main_conn):
        if conn is not None:
            conn.commit()
    self._pending = 0
```

- `ensure_taxon` / `upsert_*` 内的 `conn.commit()` 改为 `self._touch()`。
- `close()` 前先 `flush()`。
- 调用方（`download_inaturalist` 每个类群结束、`drop_crawl_interface` 每个种类结束）显式 `flush()`。

**验收**：1 万张照片导入耗时下降一个数量级（对比 `-wal` 文件写入频率）。

## 8. 不建议做的事

1. **换 Qt / Electron**：Tk 足够，缺的是分层；换框架会把结构问题原样搬过去。
2. **把训练搬进 GUI 进程**：子进程隔离是正确决策，只该换协议。
3. **继续投入源码加密**：自解密文件保护不了 Python；保护对象应是模型权重与密钥。
4. **继续加页签**：9 页已接近认知上限，新能力优先做成现有页的模式切换。
