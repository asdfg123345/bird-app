# 模型训练环境配置（鸟类 v1.7.0）

本文说明「模型训练 / 模型库 / 视觉分析」所需的 Python 环境。爬虫主程序只需
`requests` + `Pillow`，训练相关功能需要独立的 PyTorch 环境。

> 适用系统：Windows 10/11（PowerShell 示例）；Linux/macOS 命令同理。

## 1. 推荐配置

| 项目 | 最低 | 推荐 |
|---|---|---|
| 操作系统 | Windows 10 64 位 | Windows 11 64 位 |
| Python | 3.10 | 3.11（64 位） |
| 内存 | 8 GB | 16 GB 及以上 |
| 显卡 | 支持 CUDA 的 NVIDIA 显卡（可选） | 8 GB 显存及以上 |
| 磁盘 | 5 GB 可用 | 20 GB 及以上（含预训练模型与数据集） |
| 显卡驱动 | 支持所选 CUDA 版本 | 最新 Studio / Game Ready 驱动 |

说明：

- Python 3.12 也可使用；不建议 3.13 及以上的新版本，部分 PyTorch 轮子尚未覆盖。
- 无 NVIDIA 显卡时安装 CPU 版 PyTorch，功能完整但训练速度慢。
- 显存 4 GB 可跑 ViT / ResNet 小批量微调；OWL-ViT、SegFormer、Faster R-CNN 建议 8 GB 及以上。

## 2. 快速安装（Windows PowerShell）

以下命令均在源码根目录（含 `main.py` 的目录）执行，不使用硬编码盘符。

### 2.1 创建独立虚拟环境

```powershell
python -m venv .venv-train
.\.venv-train\Scripts\python.exe -m pip install --upgrade pip
```

> 如 PowerShell 禁止执行脚本，无需修改全局策略，直接使用上面的解释器路径即可，
> 或临时执行 `Set-ExecutionPolicy -Scope Process Bypass`。

### 2.2 安装 PyTorch（先看显卡驱动）

```powershell
nvidia-smi
```

`nvidia-smi` 右上角 `CUDA Version` 表示驱动最高支持的 CUDA 版本。按版本选择：

```powershell
# CUDA 12.6（与程序内置提示一致）
.\.venv-train\Scripts\python.exe -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126

# CUDA 12.1（驱动较旧时）
.\.venv-train\Scripts\python.exe -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121

# 仅 CPU
.\.venv-train\Scripts\python.exe -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
```

`torch` 与 `torchvision` 必须来自同一个索引、同一套 CUDA 版本，否则会出现 DLL 加载失败。

### 2.3 安装其余依赖

```powershell
.\.venv-train\Scripts\python.exe -m pip install -r src\requirements-train.txt
```

> 源码包解压后若 `requirements-train.txt` 与 `main.py` 同目录，则改为
> `-r requirements-train.txt`。

### 2.4 环境自检

```powershell
.\.venv-train\Scripts\python.exe -c "import torch, torchvision, transformers, timm, cv2, numpy, PIL; print('torch', torch.__version__); print('torchvision', torchvision.__version__); print('transformers', transformers.__version__); print('CUDA可用', torch.cuda.is_available()); print('GPU', torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"
```

期望输出示例：

```
torch 2.x.x
torchvision 0.x.x
transformers 4.x.x
CUDA可用 True
GPU NVIDIA GeForce RTX ...
```

若 `CUDA可用` 为 `False`：检查是否装成了 CPU 版、显卡驱动是否正常、Python 是否为 64 位。

### 2.5 在界面中选择训练解释器

打开桌面控制台 →「模型训练」页 → 选择训练用 Python 解释器：

```
<源码目录>\.venv-train\Scripts\python.exe
```

程序会自动探测 CUDA 可用性与显存，并按显存自动调整批量大小。

## 3. Conda 方式（可选）

```powershell
conda create -n bird-train python=3.11 -y
conda activate bird-train
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
pip install -r src\requirements-train.txt
```

训练页解释器选择：

```
<conda 安装目录>\envs\bird-train\python.exe
```

路径以本机 `conda info --base` 为准，不要照抄用户名。

## 4. 依赖说明

| 依赖 | 用途 | 缺失影响 |
|---|---|---|
| torch | 训练、推理、混合精度 | 训练页不可用 |
| torchvision | ResNet 等骨干、Faster R-CNN、图像变换 | 基础训练不可用 |
| transformers | ViT 物种识别、OWL-ViT 部位检测、SegFormer 分割 | 相关模型不可用 |
| timm | ResNeSt101 等骨干 | 对应模型不可用 |
| safetensors | 安全权重格式加载 | 部分模型加载失败 |
| numpy | 数组与掩码处理 | 部位训练/推理失败 |
| opencv-python | 标注、特征描述、图像绘制 | 视觉分析部分功能失败 |
| Pillow | 图像读写、缩略图 | 界面与数据导入失败 |
| requests | 数据采集、模型下载 | 爬虫与在线模型下载失败 |

## 5. 显存与批量建议

| 任务 | 建议显存 | 说明 |
|---|---|---|
| ResNet / ViT 分类微调（224） | 4–6 GB | 批量 16–32，程序会自动探测 |
| OWL-ViT 部位检测 | 6–8 GB | 单次批量前向，显存不足时降低图片尺寸 |
| SegFormer 部位分割 | 8 GB+ | 分割模型显存占用较高 |
| Faster R-CNN 检测 | 8 GB+ | 检测头与特征图占用较高 |

程序已内置显存自适应：批量过大触发 OOM 时会自动回退。也可在训练页手动降低批量大小或图片尺寸。

## 6. 国内网络加速（可选）

```powershell
# HuggingFace 镜像（首次加载 ViT / OWL-ViT 权重时使用）
$env:HF_ENDPOINT = "https://hf-mirror.com"

# pip 镜像
.\.venv-train\Scripts\python.exe -m pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

模型缓存位置：`%USERPROFILE%\.cache\huggingface`。

## 7. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `ModuleNotFoundError: torch` | 未安装或解释器选错 | 用 `.venv-train\Scripts\python.exe` 安装并在训练页选中它 |
| `torch.cuda.is_available()` 为 False | 装了 CPU 版 / 驱动异常 | 重装对应 CUDA 轮子，更新显卡驱动 |
| `DLL load failed` | torch 与 torchvision 版本/CUDA 不匹配 | 卸载后从同一索引重装 |
| `ModuleNotFoundError: transformers` | 未装训练依赖 | `pip install -r requirements-train.txt` |
| `ModuleNotFoundError: timm` | 未装 timm | `pip install timm` |
| 首次识别/检测很慢 | 正在下载预训练权重 | 保持网络畅通，或设置 `HF_ENDPOINT` 镜像 |
| CUDA out of memory | 显存不足 | 降低批量大小/图片尺寸，关闭其他占用显卡的程序 |
