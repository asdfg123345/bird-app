## 四、新增/修改文件

### 1. `packaging/build_installer.py`（新增，约 860 行）

可复现构建流水线，六步：

1. 准备打包源码：13 个运行模块复制到 `打包源码/`，注入 `_frozen_base` 冻结适配
   （**只改写代码中的路径常量，字符串字面量内的 `Path(__file__)` 不改**——
   修复了 v1.5.1 会误改 `dataset_exporter.py` 中 train_example 模板的问题），
   注入源码指纹与构建时间，复制 `model_trainer.py`、`vision_system/`、`part_model_training/`、图标；
2. 生成发布附件：GBK+CRLF 的两个 bat、UTF-8 使用说明、PE 版本资源、PyInstaller spec、Inno Setup iss；
3. PyInstaller onedir 冻结构建（约 20 秒）；
4. 部署源码形态组件到 exe 旁（训练脚本/视觉系统/部位训练/启动脚本/说明/图标）；
5. 运行 `鸟类.exe init-db` 生成预置空库（同时验证冻结形态数据目录解析）；
6. Inno Setup 编译安装包 + 调用验证脚本。

关键修复（本次实测发现）：

- **modelscope 依赖图爆炸**：`part_model_training/hub_resolver.py` 在函数内 `import modelscope`，
  PyInstaller 会跟踪该导入 → modelscope → tqdm → pandas → scipy → sphinx/matplotlib/IPython…
  依赖图膨胀到数 GB、构建 15 分钟无进展。冻结主程序只用 `hub_resolver.DEFAULT_MIRROR` 常量
  （缺失时源码已有 HF 镜像回退），且真正需要 modelscope 的是 exe 旁由外部 torch 解释器运行的
  `part_model_training` 脚本，故在 spec 中显式排除 `modelscope/numpy/pandas/scipy/matplotlib/sphinx` 等，
  构建时间降到 20 秒，安装包 19.4 MB。
- **Inno Setup 卸载静默阻塞**：`CurUninstallStepChanged` 的 MsgBox 增加 `not UninstallSilent` 判断，
  避免静默卸载被自定义弹窗阻塞（v1.5.1 脚本中的实现会阻塞）。
- Inno Setup `AppVersionInfo` 不是合法 `[Setup]` 指令，已移除（此前编译失败项）。

### 2. `packaging/verify_installer.py`（新增，约 520 行）

三种验证模式：

- `smoke <发布程序目录>`：复制到临时目录后冒烟——版本/水印、`init-db`、冻结数据目录、
  `stats`、`migrate`（离线写入 5 观察/5 照片）、`dataset` 导出（manifest 5 行）、`health`、
  `drop` 拖入导入、`panel` HTTP 200、GUI 启动存活 ≥8 秒且无异常堆栈；
  被测进程全部以「最小环境」启动（PATH 仅 System32、清除全部 PYTHON* 变量），
  证明目标机未装 Python 也能运行；
- `installer <安装包.exe>`：PE 资源/体积校验 → 静默安装到临时目录 → 快捷方式/组件校验 →
  安装目录内重跑全部冒烟 → 跨工作目录启动校验 → 静默卸载 → 校验程序文件清理、
  `data/` 用户数据保留、开始菜单快捷方式清除；
- `payload <iss>`：受限环境下的载荷级安装验证——从正式 iss 派生「无快捷方式/无卸载项」临时安装包，
  文件清单与压缩方式完全一致，用于验证安装载荷与安装后程序可用性。

## 六、环境限制（未完成项说明）

本会话运行在 DSH Windows 沙箱内，沙箱对「非直接启动的子进程」只授予工作区写入权限：

- 安装包在 **开始菜单快捷方式**（`IPersistFile::Save` → 0x80070005）与
  **卸载注册表项**（`RegCreateKeyEx` → 错误 5）两处被拒绝写入，Inno 回滚退出码 4；
- 对照实验：空白最小 Inno 安装包同样无法在真实 `%TEMP%` 初始化（退出码 1，无日志），
  而把 TEMP 指向工作区后可正常解压安装文件；
- 因此「真实安装包的快捷方式/卸载注册表/卸载流程」未能在此环境端到端执行，
  其余部分（载荷安装、安装后程序全功能、PE 资源、体积）均已验证。

**在普通桌面环境（非沙箱终端）可用一条命令完成端到端复核**：

```powershell
python packaging\verify_installer.py installer "release\鸟类_v1.7.1\安装输出\鸟类_安装包_v1.7.1.exe"
```

该命令会静默安装到临时目录、跑完全部冒烟、再静默卸载并校验数据保留。
