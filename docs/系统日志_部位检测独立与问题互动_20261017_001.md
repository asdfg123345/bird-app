## 三、项目更改日志

### 1. annotator.py：新增多框标注函数
- 新增 `annotate_multi(image_path, items, style, out_dir)`：在一张图上一次绘制
  多个部位框与中文标签，只输出一个文件；复用既有 `_clamp_box_int`、`_draw_label`、
  `_load_font`、`_measure_text`、`_next_output_path`，绘制效果与单框 `annotate()` 一致。

### 2. vqa_engine.py：一键全部位检测引擎
- 新增数据类 `PartHit`（部位结构化结果：中文名/英文名/像素框/是否估计/描述）与
  `PartsDetectAnswer`（汇总结果）；
- 新增 `detect_all_parts()`：遍历 12 个语义部位逐个直接检测（不走空间先验估计），
  检出部位生成科普式特征描述，调用 `annotate_multi` 输出全部位标注图；
- 新增粗粒度过滤：部位框与鸟体整框交并比（IoU）≥0.9 时视为"未精确定位"按未检出
  处理（占满画面的特写照片上各部位框会重叠为同一整鸟大框，失去定位意义）；
- 新增 `_iou()` 交并比计算辅助函数；
- `VqaAnswer` 数据类增补 `part_box`（部位像素框），使单部位提问结果同样可点击交互；
- 失败提示分级：未定位到鸟体→"请换清晰图片"；定位到鸟体但部位均未检出→提示
  可在问题互动中单独询问（触发空间先验估计）。

### 3. model_backends.py / model_adapters.py：检测器新增单实例框接口
- `PartDetectorBackend` 基类新增 `detect_best()`（默认退化为 `detect()` 并集框）；
- `OwlViTAdapter`、`TrainedFrcnnAdapter` 覆写 `detect_best()`：返回置信度最高的
  单实例框（多实例不合并），保证全部位检测时各部位定位点彼此区分、可独立点击；
- 单部位提问链路（`detect()` 并集框行为）保持不变，不影响既有功能。

### 4. qa_server.py：服务协议扩展
- 新增命令 `detect_parts`：请求含 image_path / marker_style / part_model，
  响应含 message / marked_image_path / parts（行结构：
  [中文名, 英文名, x1, y1, x2, y2, 是否估计, 特征描述]）/ detected_count；
- `answer` 响应增补 `part_box`、`description` 字段；
- 模块文档字符串协议说明同步更新。

### 5. gui_app.py：交互改造
- 动作按钮区改为三按钮：「部位检测（全部位）」「提问」「清空对话」；
  任一任务运行期间三按钮统一禁用（新增 `_set_action_buttons()`）；
- 新增 `_on_detect_parts` / `_detect_parts_worker` / `_on_detect_parts_done` /
  `_on_detect_parts_error`：服务模式走 detect_parts 协议，本地模式进程内调用；
- 结果文本区改造为多轮对话式（新增 `_append_dialogue()`）：物种识别、部位检测、
  问/答记录、点击部位记录均以带标题块累积追加并自动滚动到底部；
- 结果图区由 Label 改为 Canvas 画布：显示标记图并登记可点击部位框
  （原图坐标按显示缩放比换算为画布坐标）；点击命中（多框重叠取面积最小者）即在
  状态栏显示部位名称并追加对话记录（含特征描述）；鼠标悬停部位框内光标变手型；
- 删除已无引用的 `_ServiceAnswer` 适配类；
- 文案科普化：开关文案、问题互动标题、状态栏提示、占位文本同步更新。

## 六、性能与注意事项

- 一键全部位检测共发起约 13 次 OWL-ViT 前向（12 部位 + 1 次鸟体框），GPU 下
  单次约 0.5 秒，整体约 7~10 秒（首次加载模型另计）；
- 当前图库照片多为 224×224，OWL-ViT 对小图鸟体的部位定位能力有限，多数照片
  会返回"未精确定位"提示，属模型能力边界（单部位提问的空间先验估计仍是主要
  定位手段）；建议后续在发布副本内训练 FRCNN 部位检测器以改善小图定位；
- 临时测试脚本与测试生成的标注图均已清理。
