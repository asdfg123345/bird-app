## 四、去重机制（复现关键，必须一并复现）

本项目采用 SHA-256 指纹去重，来源：第二版\deduplicator_第2.py 第 123-148 行。

### 4.1 指纹生成算法

```python
import hashlib
import re

def normalize_text(text: str) -> str:
    """文本标准化：去括号内容、去标点、转小写、去空白"""
    if not text:
        return ''
    text = re.sub(r'\([^)]*\)', '', text)      # 去除括号内的变体说明
    text = re.sub(r'[^\w\s]', '', text)         # 去除标点符号
    text = text.lower()                         # 转小写
    text = re.sub(r'\s+', '', text)             # 去空白
    return text

def generate_fingerprint(title: str, content: str) -> str:
    """基于标题+内容生成 SHA-256 唯一指纹"""
    normalized_title = normalize_text(title.strip())
    normalized_content = normalize_text(content.strip())
    combined = f"{normalized_title}|{normalized_content}"
    return hashlib.sha256(combined.encode('utf-8')).hexdigest()
```

### 4.2 数据库层的去重保障

1. `poems.fingerprint` 字段 UNIQUE 约束 + `INSERT OR IGNORE` 语句 → 数据库层兜底去重
2. `poets` 表 UNIQUE(name, dynasty) → 同名同朝代诗人只存一条
3. `poem_poet` 表 UNIQUE(poem_id, poet_id) → 关联关系不重复
4. `raw_poems.ID` 字段 UNIQUE → 爬虫原始层去重

### 4.3 三层去重策略（config.json 配置）

```json
"deduplication": {
    "enabled": true,
    "methods": [
        { "type": "unique_id",   "field": "ID",                "enabled": true },
        { "type": "fingerprint", "fields": ["标题", "内容"], "algorithm": "sha256", "enabled": true },
        { "type": "composite",   "fields": ["标题", "作者", "内容"], "enabled": false }
    ]
}
```

## 七、核心写入模式（新爬虫项目参考）

### 7.1 插入数据（事务 + INSERT OR IGNORE 防重）

```python
def insert_poem(conn, poem: dict, fingerprint: str) -> bool:
    """插入一首诗：主表 + 诗人 + 关联 + 分析 + 背景，事务保证一致性"""
    cursor = conn.cursor()
    cursor.execute('BEGIN TRANSACTION')
    try:
        # 1. 插入古诗主表（fingerprint 唯一约束兜底去重）
        cursor.execute('''
        INSERT OR IGNORE INTO poems (title, author, dynasty, content, link, crawl_time, fingerprint)
        VALUES (?, ?, ?, ?, ?, ?, ?)''', (
            poem.get('title', ''), poem.get('author', ''), poem.get('dynasty', ''),
            poem.get('content', ''), poem.get('link', ''), poem.get('crawl_time', ''),
            fingerprint
        ))
        poem_id = cursor.lastrowid

        # 2. 插入诗人并建立关联
        author, dynasty = poem.get('author', ''), poem.get('dynasty', '')
        if author:
            cursor.execute('INSERT OR IGNORE INTO poets (name, dynasty) VALUES (?, ?)',
                           (author, dynasty))
            row = cursor.execute('SELECT id FROM poets WHERE name = ? AND dynasty = ?',
                                 (author, dynasty)).fetchone()
            if row:
                cursor.execute('INSERT OR IGNORE INTO poem_poet (poem_id, poet_id) VALUES (?, ?)',
                               (poem_id, row[0]))

        # 3. 插入分析信息（赏析/注释/译文）
        if poem.get('赏析') or poem.get('注释') or poem.get('译文'):
            cursor.execute('''
            INSERT OR IGNORE INTO poem_analysis (poem_id, appreciation, notes, translation)
            VALUES (?, ?, ?, ?)''', (poem_id, poem.get('赏析', ''),
                                     poem.get('注释', ''), poem.get('译文', '')))

        # 4. 插入创作背景
        if poem.get('创作背景') or poem.get('标签'):
            cursor.execute('''
            INSERT OR IGNORE INTO poem_background (poem_id, background, tags)
            VALUES (?, ?, ?)''', (poem_id, poem.get('创作背景', ''), poem.get('标签', '')))

        conn.commit()
        return True
    except Exception:
        conn.rollback()
        return False
```

### 7.2 常用查询模式（已有索引支撑）

```sql
-- 关键词搜索（命中 idx_poems_title/author，内容无索引走全表）
SELECT id, title, author, dynasty, content, link, crawl_time
FROM poems
WHERE title LIKE '%李白%' OR author LIKE '%李白%' OR content LIKE '%李白%'
ORDER BY created_at DESC LIMIT 20 OFFSET 0;

-- 按朝代筛选（命中 idx_poems_dynasty）
SELECT * FROM poems WHERE dynasty = '唐代' ORDER BY created_at DESC;

-- 诗详情联查（分析+背景+诗人）
SELECT p.*, a.appreciation, a.notes, a.translation,
       b.background, b.tags, t.name, t.dynasty AS poet_dynasty
FROM poems p
LEFT JOIN poem_analysis a   ON a.poem_id = p.id
LEFT JOIN poem_background b ON b.poem_id = p.id
LEFT JOIN poem_poet pp      ON pp.poem_id = p.id
LEFT JOIN poets t           ON t.id = pp.poet_id
WHERE p.id = ?;

-- 朝代分布统计
SELECT dynasty, COUNT(*) FROM poems GROUP BY dynasty ORDER BY COUNT(*) DESC;
```

## 八、工程实践要点（原项目已验证）

1. **连接方式**：`sqlite3.connect(db_path)` + `conn.row_factory = sqlite3.Row`（支持按列名取值）
2. **路径处理**：数据库路径相对脚本目录解析（`os.path.dirname(os.path.abspath(__file__))`），避免工作目录漂移问题；项目配置中用 config.json 集中管理路径
3. **自愈机制**：连接失败 → 备份损坏文件（`.backup` 后缀）→ 删除重建 → 重新初始化
4. **批量写入**：超过 50 条自动先备份库，再开事务逐条 `INSERT OR IGNORE`，通过 `cursor.rowcount` 区分成功/重复
5. **性能参数**（config.json）：batch_size=1000，重试 3 次、指数退避（最长 10 秒）
6. **自动备份**：批量插入前备份至 `backups/` 子目录，命名 `gushi_backup_时间戳.db`，最多保留 5 份
7. **完整性检查**：`PRAGMA integrity_check`，异常时触发重建流程
8. **VACUUM 注意**：清空数据后执行 `VACUUM` 回收空间，且不能在事务中执行
