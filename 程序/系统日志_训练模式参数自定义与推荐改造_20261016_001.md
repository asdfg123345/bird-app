## 一、提示词总结

用户提出两点需求：

1. 训练界面四种训练模式（适应/低速/高速/自定义）不再预设固定参数值，将轮数、优化器、耐心值、学习率等参数全部开放为可自定义参数。
2. 根据训练模型的架构（主流架构）、数据集大小、训练设备硬件基础，为各模式的可自定义参数给出推荐参数值。

### 2. 推荐参数决策逻辑（四维逐步修正）

1. **模式基调**：适应/自定义=轮数30+耐心10+AdamW+学习率0.001（安全优先、效果优先）；低速=轮数15+耐心6；高速=轮数10+耐心4。
2. **架构修正**：ViT 系→轮数上调20%、耐心值至少8（注意力模型收敛略慢）；ResNeSt101→推荐 SGD 优化器+学习率0.01、轮数上调10%（配合其 SGD 迁移策略）；ResNet 系→维持基准。
3. **数据量修正**：小于5000张→轮数上调50%、耐心值上调（小数据防过早停止）；大于5万张→轮数下调30%（单轮信息量大）；中等规模→维持基准。
4. **硬件修正**：无 GPU→轮数截断至15以内（CPU 训练过慢）；显存小于6GB→提示资源偏紧，批大小将由实测探测收敛到安全值。

### 3. 运行过程

1. 阅读 GUI 参数区、模式切换联动、启动训练传参代码，理清修改点。
2. 确认训练循环中耐心值为 None 时不早停，参数回退逻辑（pick 函数）天然兼容预设值为 None 的场景。
3. 依次修改 model_library.py → model_trainer.py → bird_crawler_gui.py，共三处文件、约15处编辑。
4. 语法验证：python -m py_compile 三个文件全部通过。
5. 功能验证：三种典型组合（适应+ViT+小数据+无GPU / 高速+ResNeSt101+大数据+GPU / 低速+ResNet50+中数据+GPU）推荐输出正确，修正链条与理由完整；model_trainer.py 导入正常。

### 4. 功能实现与兼容性说明

- **各模式保留的核心职责**：适应模式仍负责设备自适应推导批大小/线程/混合精度（预算比例55%、显存实测探测等机制不变）；低速模式批大小仍固定8；高速模式仍按80%预算推导；自定义模式行为不变。
- **参数优先级不变**：命令行显式传值 > 模式预设值（现多为None）> 内置默认值（轮数15/AdamW/学习率0.001/不早停）。
- **对原有功能无负面影响**：续训时仍只传轮数、其余参数从断点快照回填；批大小实测探测、分架构训练策略（差异化学习率/升温/余弦退火/标签平滑）均不受影响。
- **性能**：硬件探测仅在训练页首次构建时执行一次并缓存；数据集计数按目录缓存且50万张封顶，不产生重复开销。
